# MindIE Sim (`sim`)

Standalone repository for `mindie_sim` (`mindie-sim` CLI), providing 4-layer Ascend NPU simulation, multi-SKU capability resolution, `D2D`/`H2D`/`D2H`/`RH2D`/`RD2H` transfer bounds, periodic microstage pipeline solving, Phase 0 subgraph fusion triage, and whole-network parallel decomposition.

See `mindie-agent/docs/simulation-system.md` for architecture and invariants.
