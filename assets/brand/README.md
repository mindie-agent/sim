# MindIE Simulator (`mindie-sim`) brand assets

The orbital stacked Agent mark (three-layer Agent stack encircled by a tilted causal simulation orbit ring and satellite node) identifies `mindie-sim` within the MindIE Agent brand family.

- `sim-logo-source.png`: 1254 × 1254 master transparent PNG.
- `sim-logo.png`: 512 × 512 transparent PNG for repository READMEs and avatars.
- `sim-icon.png`: 128 × 128 compact transparent PNG for UI icons.
- `PROMPT.md`: generation prompt and visual family reference.

Brand accent: `#7045F5` (aligned to the parent [`mindie-agent`](https://github.com/mindie-agent/mindie-agent/tree/main/assets/brand) tile and alpha mask). The same high-contrast mark works on light and dark backgrounds. Preserve its aspect ratio and transparent outer margin.
