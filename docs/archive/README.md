2. **Active Guides Live in `docs/` and `docs/operators/`**: Consult [`docs/README.md`](../README.md), [`docs/architecture.md`](../architecture.md), [`docs/operator-mechanisms.md`](../operator-mechanisms.md), and [`docs/verification.md`](../verification.md) for current `mindie-sim` interfaces and invariants.
