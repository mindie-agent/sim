## Conditional MQSMLA source role

`refs/cannbot-dsl/samples/mixed_quant_sparse_flash_mla/mixed_quant_sparse_flash_mla.py`
at revision `4519e5372a8b9306f7d823688c0cb8141ee34fb1` contains
`class MqsmlaKernel` with profile name `mixed_quant_sparse_flash_mla` at lines
897–938. This matches both the native type `MqsmlaKernel___call__` and the
capture's kernel name. The retained old V4.1 stack independently shows the caller
chain `dsa_v41._forward_attention → backend.qsmla → packaged_attention →
ops.mixed_quant_sparse_flash_mla`. The new r31 binary has not been matched to
this exact source revision.

This source kernel includes address preparation, paged sparse KV fetch and
online dequantization, QK/softmax/PV, metadata-selected split partial reduction,
and attention output writes. It excludes input/output projection GEMMs, index
selection, compressor updates, host metadata generation and HcPre/HcPost. These
are conditional semantic roles for subsequent pairing, not an invented tensor
ABI. The kernel exports N/A shapes and dtypes in this capture.

The source distinguishes original FP8 rows (544 bytes, including inline BF16
scales) from compressed FP4 rows (320 bytes). Its logical head is 512 elements
(448 non-RoPE plus 64 RoPE), 64 query heads, one KV head and a 128-row key tile.
The sampled `KvCompressEpilogV2` FP8 `[pages,128,1,544]` landmark supports a
packed original cache representation; it does not identify every argument of
the N/A attention event. The current analytic BF16-cache envelope therefore
remains an explicitly incomplete representation of this native mixed-quant
path. No BF16 SCFA source recipe is bound to these events.

Other unresolved representation work includes Engram's quantized `wkv`
projection, shared host supply across replicas and exact current binary metadata
scheduling. The source anchor and these gaps are retained in each case and in
`data/verification/v41-dp8-inputs-20261030.json`. Missing native evidence does
not disable ordinary analytic simulation.
