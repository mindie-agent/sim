The directory targets 30/50/88 ms are labels; the table's measured client

The checkpoint identifier is `/mnt/weight/GLM-5.3-W4A8-INT`, mapped to the
retained **78-layer** architecture. It is not the 45-layer Flash hybrid. The
retained `serve_glm53f_w4a8.sh` SHA256 is
`3642c774841205a58d18951e41c5338989858a35ece0c9c5c3c33c71a404373d`.
It declares TP16/EP16/DP1, INT8 KV, forced EPLB, five serial MTP proposals,
configured synthetic acceptance marginals `[.8,.64,.512,.4096,.32768]`, shared
expert overlap and `FULL_DECODE_ONLY`. These are launch declarations; the
delivered directories lack resolved startup logs. The source's eight two-die
A3 packages are represented as sixteen rank devices on one node.

The cases preserve that topology and use the public steady matrix mechanism.
They do not carry old TP8 measurements, rate overrides or communication fits.
Balanced routing is explicitly tied to the retained launch declaration.
INT8 sparse KV remains an analytic representation: the currently bound source
SparseFlashAttention program supports BF16 cache and is deliberately not
selected for these inputs. INT8 scale packing and native sparse-kernel details
remain visible unresolved contracts.

compact `acceptance-20261030-glm78-v41/retained-source-evidence.json`. All three
inputs parse, and a full 78-layer body graph is constructible for a declared
q6/B1/context4096 probe. The receipt records this as graph construction, not
execution or measured accuracy. No large CSV was read, no forward was timed,
and no device workload was launched.
