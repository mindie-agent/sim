# mindie-sim 0.8.2

This release delivers $O(1)$ exact periodic pipeline compaction for `400K`–`1M` ultra-long context lengths, reduced-expert synthetic/pruned MoE structural generalization (`E in {16..128}, K in {2..8}`), and full DaVinci `arch2201` hardware profiles for the A2 (`Ascend910B*`) SKU family.

- **$O(1)$ Exact Periodic Pipeline Compaction (`mindie_sim/prediction/refill_steady.py`)**:
  - Adds `compact_periodic_pipeline`, extracting the exact coupled steady-state cycle period and peak pool high-water mark from an isolated two-period probe when `count > 32`, and folding homogeneous interior tiles in `StagedGQADecode` (`attention_decode.py`, for homogeneous requests and single KV split while retaining all causal-masked tail tiles), `StagedGQAPrefill` (`attention_prefill.py`, for homogeneous requests), `ascend_paged_mla_decode_arch35` (`paged_mla.py`), and `ascend_paged_mla_decode_arch22` (`paged_mla_arch22.py`, for single-job owners) into a coupled fluid steady-state approximation (preserving per-subblock placement isolation under external contention).
  - Matches uncompacted `PipelineProgram` `duration_ms` within `< 1e-11` relative difference in isolation (with zero error in total service work and peak pool usage) while cutting `400K / 1M` attention simulation latency from several minutes to `< 0.05s`.
- **`400K / 1M` Ultra-Long-Context Generalization**:
  - `mindie_sim/prediction/fai_decode_mapping.py`: Extends `cores <= 64` and models `SplitCoreDecodeBS1GN2` for `q == 1` when `len(requests) >= cores` (`kv_block_tile = min(max(1, 128 // group), kv_heads)` KV-head packing per batch task with single-head tail unpacking when `0 < tail_tasks <= cores // 2`), eliminating `fai_host_single_token_specialized_decoder_not_selected` errors on high-concurrency long-context batches.
  - `mindie_sim/prediction/index_pool_native.py`: Dynamically scales `block_table_columns` when request context exceeds `runtime.max_model_len` and `block_table_columns` is not explicitly fixed.
- **Reduced-Expert Synthetic & Pruned MoE Generalization (`E in {16, 32, 48, 64, 96, 128}, K in {2, 4, 6, 8}`)**:
  - `mindie_sim/model_catalog.py` (`derive_expert_pruned`): Preserves leading dense layers (`plan.ffn == "dense"`), retains `router_groups` and `router_group_topk` whenever `(e // rg) * rgt >= k` and `e % rg == 0`, resets `expert_routing_source` to `"uniform"` when resetting `expert_routing`, and propagates pruned expert configurations to `auxiliary.mtp` and `auxiliary.dspark`.
  - `mindie_sim/prediction/moe_init_mxfp8.py`: Models the source `useGatherCopy = (topk > 3)` branch in `moe_init_routing_v3_tiling_arch35.cpp`, executing `ScatterCopyExpandedXandMXQuant` per-assignment loads and quantizations without cross-`topk` input row deduplication when `topk <= 3`.
  - `mindie_sim/prediction/grouped_dequant_arch35.py`: Skips zero-row expert groups when no later assigned group on the same AIV has nonzero rows (`E <= 64`), while still raising `arch35_dequant_zero_group_stalls_later_source_owner` when an empty group precedes a later nonzero group on the same AIV (`E > 64`).
- **A2 (`Ascend910B*`) DaVinci `arch2201` Hardware Profiles & Local Query Head Admission**:
  - `mindie_sim/backends/profiles/ascend.json`: Populates CU- and frequency-scaled `mte1`, `mte2_aic`, `mte2_aiv`, `mte3`, and `fixpipe` rates, `resource_units`, `service_modes`, `kernel_invocations` (with `arch2201_baseline_extrapolation` provenance), and `fp32/hf32/int4` compute peaks across `Ascend910B1`, `Ascend910B2`, `Ascend910B2C`, `Ascend910B3`, `Ascend910B4`, and `Ascend910B4-1`, and aligns `source.pipeline.fields.hbm.rate_bytes_per_s` and `A2` architecture provenance.
  - `mindie_sim/prediction/body_defaults.py`, `indexed_attention.py`, and `indexed_quant_attention.py`: Extends single-die local query head admission for Indexed MLA to `64` (packed `int8`) and `128` (`bf16`), and models `vecDealM` two-AIV (`AIV0`/`AIV1`) row splitting across `softmax`, `probability`, `nupdate`, `update`, and `output` when `heads > 16`.
