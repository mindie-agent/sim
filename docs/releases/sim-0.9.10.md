# mindie-sim 0.9.10

[English](sim-0.9.10.en.md)

本维护版修复正式发布与自动更新交付链路。运行时继承 0.9.9 的仿真引擎，不新增模型精度或 NPU 性能测量结论；历史实验保留原始版本与来源。

- 发布从受保护主分支的 `release.yml` 启动，要求源码 CI 全部成功。
- 完整安装包、干净源码基准、校验和与旧更新器升级验收先在草稿阶段准备，验证下载字节后才创建标签并公开不可变 Release。
- 旧更新器在隔离环境中执行版本发现、真实依赖安装、整代构建和 CLI 探针；正式公开后再验证正常更新源。发布流程保存两阶段报告，随包提供 `upgrade-acceptance.json`。
- 默认更新策略继续选择最新正式组件版本，并保留已安装组件的单调版本下限。发布失败不能被报告为“已是最新”。

本版本的实际测试和基准结果以随包报告及对应 CI 为准。
